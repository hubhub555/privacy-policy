プライバシーポリシーサポート・お問い合わせ

プライバシーポリシー

本ポリシーは「ながれの庭」（以下「本アプリ」）における情報の取り扱いを説明します。

最終更新日：2026年9月26日

端末に保存する情報

本アプリは、ゲームの進み具合、完成した庭、音や表示の設定を端末内に保存します。アカウント登録は不要です。開発者のサーバーへゲームの保存データを送信する機能はありません。端末のバックアップに保存データが含まれる場合は、OSのバックアップ設定に従って管理されます。

広告と第三者サービス

本アプリはGoogle Mobile Ads SDK（AdMob）とUser Messaging Platformを使用します。広告の配信、効果測定、分析、不正利用防止、品質改善のため、Googleが次の情報を処理する場合があります。

  • IPアドレスと、IPアドレスから推定されるおおよその位置
  • 端末またはアプリに関する識別情報（許可された場合の広告識別子を含む）
  • 表示した広告、広告の操作・視聴などの利用情報
  • クラッシュ情報、起動時間などの診断・パフォーマンス情報
  • 広告やプライバシーに関する同意・選択の情報

本アプリはGPSによる正確な位置情報、連絡先、写真ライブラリへのアクセスを要求しません。ゲーム本体はインターネット接続なしでも遊べます。広告には通信が必要です。

Googleによる情報の取り扱いと保持については、GoogleのプライバシーポリシーおよびGoogleによるパートナーのサイトやアプリからの情報利用をご確認ください。

広告に関する選択

地域や設定に応じて広告の同意画面が表示されます。変更が必要な地域では、アプリの「庭の設定」にある「広告のプライバシー設定」から選択を変更できます。本アプリは、他社のアプリやWebサイトをまたいでユーザーを追跡する目的ではデータを使用しません。リワード広告の視聴は、ゲームを遊ぶための条件ではありません。

お問い合わせ時の情報

お問い合わせいただいた場合、メールアドレスとお問い合わせ内容を、返信および問題の調査に必要な範囲で使用します。対応に必要な期間保存し、不要となった情報は削除します。法令に基づく場合を除き、本人の同意なくお問い合わせ内容を第三者に提供しません。

データの削除

端末内のゲーム保存データは、本アプリの削除によって削除できます。バックアップに含まれるデータはOSの設定で管理してください。お問い合わせで提供された情報の削除については、下記窓口にご連絡ください。第三者サービスが処理する情報は、そのサービスのポリシーと設定に従います。

ポリシーの変更

機能や情報の取り扱いが変わる場合、本ページの内容と最終更新日を更新します。新たな同意が必要な変更については、適切な方法で確認します。

よくある質問

遊び方は？
「庭をはじめる」を押し、砂のある場所を指でなぞります。砂を取り除くと水がめぐり、花が咲きます。5つの区画を完成させると、庭がアルバムに残ります。

途中でやめても大丈夫？
進み具合は自動保存されます。ホームの「つづきから」で再開できます。

広告が読み込まれません。
通信状況や広告の配信状況により表示されないことがあります。広告なしでも通常のゲーム進行は可能です。

保存データのエラーが表示されます。
既存データを保護するため、読み込みを停止する場合があります。データを残したい場合は、アプリを削除せず、お問い合わせください。
