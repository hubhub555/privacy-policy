# ツリアイ工房 プライバシーポリシー

運営者：Takumi Nakamura。施行日・最終更新日：2026年10月19日。

ツリアイ工房は、進行中の盤面、手数記録、ヒントの閲覧状況、お手本券、広告表示の頻度管理に必要な情報を端末内に保存します。アカウント登録はなく、独自サーバーへのゲーム記録送信や独自のアクセス解析は行いません。記録はアプリを削除すると失われる場合があり、端末間の同期や引継ぎは提供しません。

広告にはGoogle Mobile Ads SDKおよびUser Messaging Platformを利用します。広告を要求する場合、広告の配信・測定・不正防止などのため、広告SDKが端末情報、広告操作、診断情報、概略の位置などを扱う可能性があります。非パーソナライズ広告を要求し、パブリッシャーのファーストパーティIDを無効にします。広告SDKはIPアドレス、おおよその位置、端末やアプリの識別情報、広告の表示・操作・視聴、製品操作、クラッシュ・性能・その他の診断情報、同意の選択を処理する場合があります。IDFAの利用許可を要求しません。

必要な場合、広告のプライバシー設定をアプリの設定画面から開けます。広告の可否にかかわらず、本編・ヒント・戻す・やり直しを利用できます。リワード広告は任意で、お手本券の付与は視聴完了の通知があった場合に行います。

Googleのデータ利用については [Googleのプライバシーポリシー](https://policies.google.com/privacy) を参照してください。

お問い合わせ時のメールアドレスと内容は返信と調査に必要な範囲・期間で扱い、不要になった情報は削除します。法令に基づく場合を除き、同意なく問い合わせ内容を第三者に提供しません。削除のご希望は下記窓口へご連絡ください。端末のバックアップはOS設定で管理してください。Googleが扱う情報は同社のポリシーに従います。取り扱いが変わる場合は本ページを更新します。

# ツリアイ工房 サポート

重りを運んで道を作る、時間制限なしのパズルです。床を選び、「移動」「持つ」「置く」を選んで予告を確認し、「決定」を押します。印をすべて回収し、手ぶらで出口へ進むとクリアです。

- 手ぶらなら一段上または一段下へ。運搬中は同じ高さか一段下へ進めます。 - 同じ記号の台は対です。重りを片側に置くと、相手の台の上面が上がります。 - 困ったら無料の2段階ヒント、直近256手の「戻す」、無制限の「最初から」を利用できます。 - 最初の面のお手本は無料。他の面は、利用条件を満たしたときの任意広告で獲得する券を使って解放できます。広告が利用できなくても本編はすべて遊べます。 - 記録・券はこの端末のみです。端末変更や再インストールで引き継ぐ機能はありません。 - 保存エラー時はストレージの空きを確認し「保存を再試行」を選んでください。未保存の報酬は強制終了すると復元できない場合があります。

お問い合わせは、アプリ版番号、端末・iOSの版、面ID、操作内容を添えてください。個人情報を含む画面や広告識別子は送らないでください。
